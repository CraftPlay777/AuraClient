# ¿Que es esto?
AuraClient es un cliente hack para luanti,osea una versión modificada de luanti para hacer trampas.

# ¿Que lo hace especial a otros HackClient de luanti?
Lo especial de este cliente es que 
- Está especializado para Android
- Está basado directamente en la última versión de Luanti (5.17.0)
- No te mete 100 HUD's de colores que te tapan toda tu pantalla
- Está en español

# Inclusiones actuales
- Tiene priv default de fly
- Tiene priv de noclip
- Tiene priv de fast

## Comandos locales
Puedes usar:
### speed
- .speed {bloques por segundo} | para configurar tu velocidad (No te pases de 3)
- .speed off | apaga la velocidad confugurada y usa directo la del server.
