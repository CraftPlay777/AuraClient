# ¿Que es esto?
AuraClient es un cliente hack para luanti,osea una versión modificada de luanti para hacer trampas.

# ¿Que lo hace especial a otros HackClient de luanti?
Lo especial de este cliente es que 
- Está especializado para Android
- Está basado directamente en la última versión de Luanti (5.17.0)
- No te mete 100 HUD's de colores que te tapan toda tu pantalla
- Está en español

# Inclusiones actuales
- Tiene priv default de fly
- Tiene priv de noclip
- Tiene priv de fast

## Comandos locales
### speed

- configurar tu velocidad (No te pases de 3)
```
.speed {bloques por segundo}
```
---
apaga la velocidad configurada y usa directo la del server.
```
.speed off
```
---

# Compilación 
Puedes compilar este repo haciendo lo siguiente:

- Haz un fork de este repo.
- Dirígete a la sección de "Actions" de arriba de tu repo
- Ve a worlflows
- Busca "Build Luanti APK" y presionarlo
- Toca en "Run"
- Ahora espera unos 15 minutos y la APK se compilará para las 4 arquitecturas Android.
- Descarga el zip de abajo
- Instale el APK de tu arquitectura Android
- Listo

# Información de HackClient
Este hack client funciona a base de la modificación de 4 archivos dentro de src/client.
En la V1 ,la carpeta /clientmods/ no tiene función ya que los mods hacks se manejan directo en c++ code.

# Instalación 
- Ve a [Este sitio](https://github.com/CraftPlay777/AuraClient/releases/tag/V1)
- Busca tu tu arquitectura Android (Nota: Normalmente ,si tú celular es algo viejo ,es armv7l ,si es un celular más moderno probablemente sea arm64v8 ,los otros creo que eran para emuladores Android.
- Descarga el archivo
- Instala la APK
- Listo
